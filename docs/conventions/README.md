# Authoring conventions

Project-specific rules for contributors. Start with [organizing principles](organizing_principles.md) to decide where a statement belongs and which readers it serves.

- [Code style](code_style.md) — interface documentation, tensor contracts, and implementation conventions.
- [Naming](naming_conventions.md) — symbols and source organization.
- [Markdown style](markdown_style.md) — document structure and formatting.
- [Prose style](prose_style.md) — explanations matched to their audience.

Model readers can consult the [glossary](glossary.md), [notation](notation_conventions.md), and [parameter sources](module_parameter.md) directly from the scientific reference.
