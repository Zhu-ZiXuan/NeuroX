# Current ADC family

The current ADC family digitizes a single-ended magnitude current into an unsigned integer code. An abstract family contract plus its concrete topologies.

- [base](family.md) — the abstract `CurrentAdc` contract: single-ended magnitude input, unsigned-code convention, what the ADC does and does not own.
- [sar](sar.md) — the triple-margin current-mode successive-approximation ADC.
