# 1T1R array

The 1T1R array joins a grid of [cell](../cell/1t1r.md) sites with resistive-capacitive interconnect, driven at the word lines and clamped at the bit-line and source-line boundaries. Each site is a two-terminal element between a bit-line node and a source-line node whose internal device topology the cell condenses. An array solve takes the analog word-line drive and the two boundary port voltages, settles the array to a DC operating point under the interconnect parasitics, and yields the per-column boundary current and port voltage.

## Physical model

A cell at column $c$, row $k$ presents a two-terminal branch between its bit-line node $V_{\mathrm{BL},k}$ and source-line node $V_{\mathrm{SL},k}$, gated by the word-line voltage $V_{\mathrm{WL},k}$. The branch current and its two signed terminal conductances come from the [cell](../cell/1t1r.md), which condenses its own internal node; the array model treats each cell as that condensed element and does not see the internal node. Two boundary clamp drivers close the circuit: the BL port voltage $V_{\mathrm{BL,port}}$ held by the BL clamp driver absorbing the column's BL port current, and the SL port voltage $V_{\mathrm{SL,port}}$ from the SL driver. The word line is an input: $V_{\mathrm{WL},k}$ is the analog word-line drive.

The array is a uniform lattice of identical cell sites: one row pitch, one column pitch, one link resistance per rail between adjacent sites, and one total capacitance to ground at each circuit node. Each column's BL/SL rails are resistive ladders along the row axis whose element zero — the link from the boundary to the first site — spans one standard pitch like every other element; whatever lead-in a boundary driver needs to reach that first site is a parasitic of the driver, not of the lattice. The word line is the driven boundary and carries no DC conduction path; it enters the array as the gate drive at each site's WL node.

## Governing equations

The DC operating point of one column over $N_{\mathrm{row}}$ cells has unknowns $\{V_{\mathrm{BL},k}, V_{\mathrm{SL},k}\}_{k=0}^{N_{\mathrm{row}}-1}$ plus the boundary scalars $V_{\mathrm{BL,port}}, V_{\mathrm{SL,port}}$. The internal cell node is not an array unknown — each cell condenses it and reports a single branch current $I_{\mathrm{cell},k}(V_{\mathrm{BL},k}, V_{\mathrm{SL},k})$ (positive from $V_{\mathrm{BL}}$ to $V_{\mathrm{SL}}$) with its two signed terminal conductances, per [cell](../cell/1t1r.md). The residuals are the per-node wire-ladder KCL on the BL and SL rails,

$$F_{\mathrm{BL},k} = \operatorname{wire}_{\mathrm{BL},k}\!\left(V_{\mathrm{BL}}, V_{\mathrm{BL,port}}\right) + I_{\mathrm{cell},k}\!\left(V_{\mathrm{BL},k}, V_{\mathrm{SL},k}\right) = 0,$$

$$F_{\mathrm{SL},k} = \operatorname{wire}_{\mathrm{SL},k}\!\left(V_{\mathrm{SL}}, V_{\mathrm{SL,port}}\right) - I_{\mathrm{cell},k}\!\left(V_{\mathrm{BL},k}, V_{\mathrm{SL},k}\right) = 0,$$

and the two boundary constraints pinning the port voltages to the clamp drivers' transfer functions at the port current,

$$F_{\mathrm{CL,BL}} = V_{\mathrm{BL,port}} - \operatorname{driver}_{\mathrm{BL}}\!\left(I_{\mathrm{BL,port}}\right) = 0, \qquad I_{\mathrm{BL,port}} = G_{\mathrm{seg}}\,\left(V_{\mathrm{BL,port}} - V_{\mathrm{BL},0}\right),$$

$$F_{\mathrm{CL,SL}} = V_{\mathrm{SL,port}} - \operatorname{driver}_{\mathrm{SL}}\!\left(I_{\mathrm{SL,port}}\right) = 0, \qquad I_{\mathrm{SL,port}} = G_{\mathrm{seg}}\,\left(V_{\mathrm{SL,port}} - V_{\mathrm{SL},0}\right),$$

the boundary link being one standard pitch of the same ladder.

The same condensed branch current leaves the BL rail ($F_{\mathrm{BL}}$ injects $I_{\mathrm{cell}}$) and enters the SL rail ($F_{\mathrm{SL}}$ draws it), so the array sees one current per cell with no internal-node residual. The cell branch $I_{\mathrm{cell}}(\cdot)$ — set by the RRAM conductance $G_{\mathrm{RRAM}}$ in series with the access NMOS — is specified in [cell](../cell/1t1r.md); the boundary functions $\operatorname{driver}_{\mathrm{BL}}(\cdot)$, $\operatorname{driver}_{\mathrm{SL}}(\cdot)$ follow the [voltage-driver](../../analog/voltage_driver.md) transfer characteristic. The operating-point solution yields the per-column BL port current $I_{\mathrm{BL,port}}$ and BL port voltage $V_{\mathrm{BL,port}}$.

## Numerical method

The array operating point is solved by damped Newton iteration: a port Newton on the clamp pair $(V_{\mathrm{BL,port}}, V_{\mathrm{SL,port}})$ wraps a node coupled block-$2\times2$ wire Newton on $(V_{\mathrm{BL}}, V_{\mathrm{SL}})$ along the row axis, with each cell condensing its internal node at every step. The formulation, its well-posedness, and the block-tridiagonal linear algebra are specified in [solver](../solver/col_bl_col_sl.md).

## Noise & non-idealities

The array owns no static mismatch of its own; non-idealities enter through the cells: per-cell RRAM conductance non-idealities and access-NMOS mismatch, carried inside the condensed branch — see [cell](../cell/1t1r.md). The boundary clamp-driver and word-line-drive non-idealities are properties of those blocks, not of the array.

Device variation enters through the sampled cell branch; boundary variation enters through the held driver state. Their distributions belong to the device and peripheral models, and each realization is held fixed during numerical settling.

## Energy model

One array operation establishes the BL/SL boundary levels, executes one or more WL phases while those levels are held, and then releases the boundaries. The macro identifies the WL phase axes; the array assigns no further meaning to them. All capacitive terms follow the supply-draw law $E = V_{\mathrm{rail}} C \lvert\Delta V\rvert$ of [capacitive energy](../../physics.md).

For phase $p$, each node is billed once for its round-trip displacement from the held rest state to the solved operating point and back. Every node draws charge from the core analog supply $V_{\mathrm{DD}}$:

$$E_{\mathrm{phase},p} = V_{\mathrm{DD}} \sum_{c,k} \Big[C_{\mathrm{BL}}\lvert V_{\mathrm{BL},p,c,k} - V_{\mathrm{BL},c}^{\mathrm{rest}}\rvert + C_{\mathrm{X}}\lvert V_{\mathrm{X},p,c,k} - V_{\mathrm{BL},c}^{\mathrm{rest}}\rvert + C_{\mathrm{SL}}\lvert V_{\mathrm{SL},p,c,k} - V_{\mathrm{SL},c}^{\mathrm{rest}}\rvert + C_{\mathrm{WL}}\lvert V_{\mathrm{WL},p,k}\rvert \Big].$$

The rest state is declared rather than solved: BL and the internal access node sit at the zero-load BL boundary level, SL sits at the zero-load SL boundary level, and WL rests at ground. Establishing and releasing those held BL/SL levels costs

$$E_{\mathrm{rest}} = V_{\mathrm{DD}} N_{\mathrm{row}} \sum_c \Big[(C_{\mathrm{BL}} + C_{\mathrm{X}})\lvert V_{\mathrm{BL},c}^{\mathrm{rest}}\rvert + C_{\mathrm{SL}}\lvert V_{\mathrm{SL},c}^{\mathrm{rest}}\rvert\Big].$$

It is charged exactly once for the complete phase group, not divided across rows or repeated for every phase:

$$E_{\mathrm{operation}} = E_{\mathrm{rest}} + \sum_p E_{\mathrm{phase},p}.$$

All phases in one group must share the same zero-load BL/SL boundary levels. A changed boundary reference starts another operation and requires another array call.

Read-current DC conduction ($V \cdot I \cdot t$) is not part of the array energy model because the solve has no conduction-duration input.

The static PPA follows from the same lattice. Its silicon area is $N_{\mathrm{row}} N_{\mathrm{col}}$ sites at one row pitch by one column pitch. Static leakage is zero because the operation releases its boundaries and returns the cells to zero bias; driven conduction is outside the static model.

## Assumptions, scope & validity

- Interconnect is lumped, not distributed: a per-link resistance ladder along each rail and one total capacitance to ground at each circuit node.
- The lattice is uniform: one pitch per axis and one link resistance per rail, the boundary link included, so a driver's own lead-in is outside the array.
- The WL line carries no DC conduction path and enters only as the gate drive at each site's WL node.
- Every parasitic capacitance is referenced to ground and completes its excursion within the access, so the displacement alone sets its cost; coupling capacitance between two signal nodes is not represented.
- All WL phases in one array call share one ideal BL/SL rest boundary; a boundary change starts a new call.
- The solve is quasi-static: it finds the DC operating point and does not model transient device switching within a pulse.

Quantitative geometry and array-size limits are not established here. The quasi-static model does not predict frequency-dependent interconnect or switching transients.
