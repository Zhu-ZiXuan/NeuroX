# Calibration

Use calibration tools to characterize a configured circuit or derive parameters for a stated operating point. Start with [running calibration tools](tool_conventions.md), then choose the task:

- [Cell linearization](solver_tolerances.md) — extract conductance and divider tables from a detailed cell.
- [ADC input characterization](calibrate_adc.md) — collect input distributions for reference selection.
- [Macro rescaling](calibrate_macro.md) — determine the scale of final output codes.
