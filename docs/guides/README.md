# Guides

Task-oriented how-to guides, grouped by the goal you have in mind.

| Guide | Audience | Status |
|---|---|---|
| [algorithm_engineer](algorithm_engineer/README.md) | evaluate a model's accuracy & energy on a real circuit | seeded from `example/` (manual operator replacement) |
| architecture-engineer | build / evaluate a macro (a new array organization) | seeded from "how the bundled macros are built"; interface still maturing |
| calibration | fit model parameters (e.g. ADC rescale) to a chip | planned |
| benchmarking | run the standard suite, define & report metrics, reproduce a number | planned |
| performance-scaling | control solver memory / runtime (chunking, dtype) | planned |

A dedicated device-engineer guide is **not yet available** — the device plug-in interface is on the [roadmap](../about/README.md), not yet implemented.
