# Python API

The root `neurox` package exposes the application API. Extension authors use the owning bases, mixins, and family interfaces. Contracts live in their docstrings; the application reference below is generated by `mkdocstrings`.

## User API

- **Operators** — `neurox.architecture.unit` exports `LinearUnit` and `Conv2dUnit`; their `linear` and `conv2d` packages provide CIM and ideal implementations. The [unit family](../reference/architecture/unit/family.md) specifies their integer operators.
- **File construction** — `neurox.linear_unit_from_file`, `neurox.conv2d_unit_from_file`, `neurox.cim_macro_from_file`, `neurox.iadc_from_file`, and `neurox.diff_vadc_from_file` construct their respective families from [configuration files](configuration.md).
- **Lifecycle** — `neurox.fabricate` and `neurox.set_temperature` operate on assembled models under the [physical-state lifecycle](../system_design/physical_state.md).
- **Measurement** — `neurox.stamp_names`, `neurox.set_profile_leading_rank`, `Profiler`, and `Reporter` prepare the hardware tree, retain basic-operation observations, and derive PPA data. Applications select hardware scope and perform subsequent statistics and task scheduling under [PPA accounting](../system_design/ppa_accounting.md).

Primitive families under `neurox.primitive` provide standalone components and the children units compose. Device classes are imported from their public modules, such as `neurox.primitive.device.mosfet`, rather than the aggregate device package.

## Extension SPI

- **Module families** — `neurox.common.module.ProfileModule`, `NonProfileModule`, `ConfigBase`, and `PolicyBase`.
- **Construction constraints** — `neurox.common.base_only_mixin.BaseOnlyMixin`.
- **Family dispatch** — `neurox.common.registry_mixin.RegistryMixin` and each family's `register_neurox_impl` decorator.
- **Serialization and validation** — `neurox.common.serialize_mixin.SerializeMixin`, `neurox.common.validate_mixin.ValidateMixin`, and `neurox.common.serialize`.
- **Cross-module data** — `neurox.common.module.SnapBase` and `DcopBase`.
- **Recording** — `neurox.common.recorder.RecorderBase`.
- **Operator interfaces** — `neurox.architecture.unit.UnitBase`, `UnitConfig`, `LinearUnit`, and `Conv2dUnit`; `CimUnit` supplies shared CIM matrix execution.
- **Digit encoding** — `neurox.encoding.Transcoder`.
