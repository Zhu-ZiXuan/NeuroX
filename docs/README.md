# NeuroX documentation

NeuroX is a PyTorch simulator for RRAM compute-in-memory hardware — device physics, analog/digital circuits, and array/macro architecture — reporting algorithmic accuracy alongside circuit-level PPA.

- [Validation](validation/README.md) — how a model is shown faithful, and where the per-paper campaign evidence under `validations/` lives
- [API](api/README.md) — what the public Python surface exposes, and what a config or policy file may hold
- [System design](system_design/README.md) — which software contracts span components and which component owns each end, by topic
