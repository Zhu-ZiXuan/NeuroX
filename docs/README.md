# NeuroX Documentation

NeuroX is a PyTorch simulator for RRAM compute-in-memory hardware — device physics, analog/digital circuits, and array/macro architecture — reporting algorithmic accuracy alongside circuit-level PPA.

Find a section by what you are doing:

- [Get started](get-started/README.md) — install, quickstart
- [Guides](guides/README.md) — task how-to, by audience (algorithm / architecture / device engineer)
- [Reference](reference/README.md) — the scientific spec (physical models, equations, numerical methods), by subsystem
- [Validation](validation/README.md) — evidence the models are faithful and correctly implemented
- [API](api/README.md) — Python API and config / policy schema
- [Internals](internals/README.md) — how the codebase is built
- [Contributing](contributing/README.md) — conventions, recipes, workflow
- [About](about/README.md) — roadmap, decisions, citation

Reference (the spec) and Internals (the implementation) are deliberately separate: core code is a programmatic translation of Reference.
