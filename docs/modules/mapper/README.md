# Mapper Modules

This directory documents the value-domain primitives shared by every xbar macro mode.

## Files

- [`transcoder/`](transcoder/README.md) — signed-digit encoding policies (`true_form` / `complement` / `canonical`), one subclass per file.
- [`xbar/`](xbar/README.md) — `Slicer` family (`SerialSlicer` for `Sa`, `SimpleSlicer` for `Sw`).
